# Hi, I am yvdist (Yudistira Eka Pratama)

Senior software engineer in South Jakarta. I build full-stack web applications, enterprise systems and AI-driven apps for clients across ASEAN.

On the backend I work mostly in PHP and Laravel. On the frontend I move between React, Next.js, Svelte, Angular and whatever the project needs. Lately most of my work is AI-driven — assistants, document pipelines and tools that put language models to practical use.

---

### What I'm working on

- **Interactive Mall Directory** — touchscreen wayfinding across multiple floors in 2D and 3D, with Dijkstra-based routing, a three.js walkthrough and a full admin panel. Live in production across several malls of a major retail group in Malaysia.
- **Mall AI Assistant** — a conversational layer on top of the directory, grounded in live tenant data through RAG so it answers from facts, not from what the model remembers.
- **HRIS Platform** — attendance, leave, KPIs, payslips and org chart for ~80 employees. Angular/Ionic PWA with a role-based admin dashboard.
- **Recruitment Platform** — AI-based CV parsing that extracts candidate details, work history and skills from uploaded documents. In production.
